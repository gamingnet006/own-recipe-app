# Security Policy

## Supported Versions

Only the latest release of Kochheft gets security fixes. Installations with automatic updates switched on
(`kh/ops/auto_update.sh on`) receive them overnight.

## Reporting a Vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/privately-reporting-a-security-vulnerability):
the **"Report a vulnerability"** button on the [Security tab](../../security/advisories/new) of this repository.

Kochheft is a fork of [Mealie](https://github.com/mealie-recipes/mealie). If the problem is in Mealie's own code and
also affects Mealie, please report it to the Mealie project as well; Kochheft takes over Mealie's security fixes.
